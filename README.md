# Nice Shop

Nice Shop is an online store for phones, tablets and accessories. Users can browse product catalogs, filter and sort items, view detailed product pages with photo galleries and technical specs, add products to a shopping cart, and save favorites — all with state persisted in the browser.

## Live Preview

- [DEMO LINK](https://artembaranovsky1.github.io/react_phone-catalog)

## Technologies Used

- React
- TypeScript
- React Router
- Sass (SCSS)
- Bulma
- Swiper
- Vite
- Cypress

## Getting Started

Clone the repository:

```
git clone https://github.com/artembaranovsky1/Nice-Shop.git
cd Nice-Shop
```

Install dependencies:

```
npm install
```

Run the project locally:

```
npm start
```

## Features

- Product catalogs for phones, tablets and accessories with filtering and sorting
- Product details page with a photo gallery, color and capacity selection, and technical specs
- Shopping cart with quantity management
- Favorites list
- Responsive layout for desktop and mobile
